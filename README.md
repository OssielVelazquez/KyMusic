# 🎵 KyMusic

**KyMusic** is a modern Android music player developed with **Kotlin** and **Jetpack Compose**, focused on providing a clean, customizable and fully local music playback experience.

## 📱 About the project

KyMusic allows users to browse and play music stored locally on their Android device, manage playlists, customize the player interface and adjust audio settings through a built-in equalizer.

The project was developed as a personal software project to practice and demonstrate Android development, UI design, media playback and application architecture.

## ✨ Features

* 🎵 Local music playback
* 📂 Browse music stored on the device
* ▶️ Play, pause, previous and next track controls
* 📋 Queue management
* 🎶 Playlist support
* 🎚️ Built-in equalizer
* 🎨 Customizable player colors
* 🌈 Audio visualizer
* 🖼️ Album artwork and music placeholders
* 🌙 Dark-themed interface
* 📱 Android Splash Screen
* 🔄 Media playback service for background playback
* 📢 Ad integration

## 🛠️ Technologies

* **Kotlin**
* **Jetpack Compose**
* **Android SDK**
* **Media3 / ExoPlayer**
* **Android MediaStore**
* **Material Design**
* **Gradle**

## 🎯 Purpose

KyMusic is a personal portfolio project created to demonstrate practical experience developing Android applications with Kotlin and Jetpack Compose.

The project includes UI development, media playback, Android services, local device storage access, audio processing and application state management.
